How It Works
The exact math behind every prediction
🧮 Prediction Formula
// Step 1 — compute historical consumption factor per meal
avg_cf = (full_count × 1.0 + half_count × 0.5 + skipped × 0.0) / 210 students

// Step 2 — scale to today's headcount
base_portions = headcount × avg_cf

// Step 3 — add 5% safety buffer (never run out)
portions_to_prepare = ceil(base_portions × 1.05)

// Step 4 — estimate leftover
expected_leftover = portions_to_prepare − (headcount × avg_cf)
📉 Confidence System (based on standard deviation)
HIGH CONFIDENCE
Standard deviation ≤ 0.35
Consistent eating pattern. Safe to use this prediction directly.
Dosa Uttapam, Amritsari Naan Chole
MEDIUM CONFIDENCE
Standard deviation 0.35–0.44
Moderate variance. The 5% buffer should cover normal fluctuation.
Rajma, Chole Paneer, most meals
LOW CONFIDENCE
Standard deviation > 0.44
High variance. Add an extra manual buffer or ask the manager.
Idli Sambhar, Poha
